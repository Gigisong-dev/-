## [1.3.0] - 2026-09-01

### 变更
- **描述规范优化**：frontmatter 与 .nio-skill.json description 增加 `Use when the user wants to collect and classify user feedback from Feishu/Lark group chats` 触发条件句式
- **不触发边界**：description 与正文新增 `Do NOT use for` 场景（非飞书群聊来源、一次性临时任务、直接在群聊中回复用户、生成知识库条目/文档、负责人分配、问题归并）
- **结构瘦身（渐进式披露）**：SKILL.md 从 500+ 行压缩至 402 行，内联详情拆分到 references/
  - 新增 `references/message-structure.md`（统一消息结构）
  - 新增 `references/output-format.md`（完整输出结构与字段规则）
  - 保留 references/classification-rules.md、field-mapping-guide.md、image-processing-guide.md、technical-architecture.md
- **任务流优化**：12 个工作流阶段逐一标注 **输入/输出**（如 阶段2 输入 chat_id+time_window → 输出 message[]）
- **Verify 步骤**：阶段 11 数据写入后新增 Verify 子步骤（核对写入记录数 == collected_count、抽查字段合法性、失败修复后重跑、向用户报告）
- **强约束强化**：`## Critical：强约束` 改为 13 条 `- [ ]` checklist 格式
- **重试机制**：新增章节（最多 3 次、指数退避 1s→2s→4s、可重试/不可重试失败类型、放弃条件）
- **耗时与超时说明**：新增章节（拉取/图片下载/上传/写入预期耗时、单命令超时阈值 60s）
- **输入 → 输出示例**：SKILL.md 内嵌 2 个示例（技术问题、产品建议），并引用 examples/basic-usage.md
- **依赖声明**：frontmatter 声明 `allowed-tools: [Bash, Read, Write]`
- **前置条件章节**：新增（lark-cli 安装、Lark 认证、表格权限、群聊权限、云空间上传权限，含检查命令）
- **参考资料索引**：SKILL.md 末尾新增"参考资料（渐进式披露）"表格
- 同步更新 PROJECT_STRUCTURE.md（新增两个 reference 文件条目）

## [1.2.0] - 2026-09-01

### 变更
- **分类标准默认改为四大分类**：默认分类标准为 `技术问题` / `产品建议` / `使用咨询` / `待划定`
  - 原"产品建议不录入反馈表、直接过滤"逻辑取消：默认标准下产品建议纳入收集和分类
  - 仅当用户提供的自定义分类标准不含产品建议分类时才过滤掉
- **支持用户自定义分类标准**：用户提供具体分类时，使用用户分类标准，不再使用默认四分类
- **知识库命中规则调整**：用户未提供知识库时，不填充"是否命中知识库"字段（空字符串 `""`），跳过命中判断，且不影响一级分类判定
  - 提供知识库时，命中判断覆盖 `技术问题` / `产品建议` / `使用咨询` 三个分类
- **配置阶段新增**：询问用户分类标准（默认四分类或自定义分类）
- **输出新增**：`config_summary` 增加 `classification_standard` 字段；`dimension_summary` 默认四分类键（用户自定义分类时使用用户定义的键）
- 同步更新配套文档（README、references、examples、PROJECT_STRUCTURE、.nio-skill.json 描述）

### 功能特性
- **消息拉取**: 支持按群名或群链接拉取消息
- **时间窗口**: 支持自定义时间范围和默认调度规则
- **反馈筛选**: 自动过滤无效消息
- **分类系统**: 三大分类 + 置信度评估
- **上下文补全**: 智能补充依赖前文的短消息
- **标准��处理**: 生成标准化标题便于后续归并
- **图片处理**: 完整的图片处理流程
- **重复识别**: 基于语义的重复问题识别
- **数据写入**: 支持自定义字段映射
- **输出校验**: 严格的约束校验确保数据质量
