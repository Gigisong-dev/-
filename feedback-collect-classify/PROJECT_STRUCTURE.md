# 项目文档结构

## 概述

feedback-collect-classify 技能现已具备完整的标准文档结构，便于用户使用、开发者贡献和系统维护。

## 目录结构

```
feedback-collect-classify/
├── SKILL.md                      # 技能核心说明文档
├── README.md                     # 用户使用指南
├── CHANGELOG.md                  # 版本更新日志
├── CONTRIBUTING.md               # 贡献者指南
├── LICENSE                       # 许可证文件
├── PROJECT_STRUCTURE.md          # 项目结构说明（本文件）
├── .nio-skill.json              # 技能元数据配置
├── SKILL_OLD.md                 # 旧版技能文档（备份）
├── examples/                    # 使用示例目录
│   └── basic-usage.md          # 基本使用示例
└── references/                  # 技术参考文档目录
    ├── classification-rules.md  # 分类规则详解
    ├── field-mapping-guide.md   # 字段映射指南
    ├── image-processing-guide.md # 图片处理指南
    └── technical-architecture.md # 技术架构文档
```

## 文档说明

### 核心文档

#### SKILL.md
- **用途**: 技能的主要说明文档
- **内容**: 完整的技能说明、工作流程、配置选项、输出格式
- **目标读者**: NIO Chat Agent、开发者
- **更新频率**: 随功能更新

#### README.md
- **用途**: 用户使用指南
- **内容**: 功能概述、快速开始、使用示例、注意事项
- **目标读者**: 最终用户
- **更新频率**: 随版本更新

#### CHANGELOG.md
- **用途**: 版本历史记录
- **内容**: 各版本的变更记录、新增功能、修复问题
- **目标读者**: 所有用户
- **更新频率**: 每次发布

#### CONTRIBUTING.md
- **用途**: 贡献者指南
- **内容**: 如何贡献代码、开发规范、提交流程
- **目标读者**: 开发者
- **更新频率**: 按需更新

#### LICENSE
- **用途**: 许可证文件
- **内容**: 使用权限和限制
- **目标读者**: 所有用户
- **更新频率**: 极少更新

### 配置文件

#### .nio-skill.json
- **用途**: 技能元数据配置
- **内容**: 技能名称、版本、描述、创建者信息
- **目标读者**: NIO Chat 系统
- **更新频率**: 版本更新时

### 示例文档

#### examples/basic-usage.md
- **用途**: 基本使用示例
- **内容**: 10个详细的使用场景示例
- **目标读者**: 用户、开发者
- **更新频率**: 随功能扩展

- **更新频率**: 规则调整时

#### references/field-mapping-guide.md

- **内容**: 标准字段定义、自定义映射、验证规则

- **更新频率**: 字段变更时

#### references/image-processing-guide.md
- **用途**: 图片处理指南

- **内容**: 统一消息结构定义、字段说明、上下文补抓规则
- **目标读者**: 开发者、配置人员
- **更新频率**: 消息结构调整时

#### references/output-format.md
- **用途**: 输出格式指南
- **内容**: 完整输出结构、字段规则、校验清单

## 文档更新策略

### 更新优先级

1. **高优先级**: SKILL.md、README.md
   - 功能变更时必须更新
   - 保持与实际功能一致

2. **中优先级**: examples/、references/
   - 新功能添加时更新
   - 优化改进时更新

3. **低优先级**: CONTRIBUTING.md、PROJECT_STRUCTURE.md
   - 开发流程变更时更新
   - 项目结构调整时更新

### 更新检查清单

在更新代码时，检查以下文档是否需要更新：

- [ ] SKILL.md - 功能说明是否准确
- [ ] README.md - 用户指南是否完整
- [ ] examples/ - 是否需要新示例
- [ ] references/ - 技术文档是否更新
- [ ] CHANGELOG.md - 是否记录变更
- [ ] .nio-skill.json - 版本号是否更新
