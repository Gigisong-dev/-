# 字段映射指南

## 概述

本指南详细说明 feedback-collect-classify 技能中的字段映射规则和配置方法。

## 标准字段定义

### 必需字段

#### SourceID
- **类型**: 文本
- **描述**: 消息唯一标识符
- **来源**: 飞书消息的 message_id
- **用途**: 去重和追溯
- **示例**: `om_xxxxxxxxxxxxxxxx`

#### 反馈时间
- **类型**: 日期时间
- **格式**: `yyyy/MM/dd HH:mm`
- **描述**: 消息发送的时间
- **来源**: 飞书消息的 create_time
- **示例**: `2026/08/19 14:30`

#### standard_title
- **类型**: 文本
- **描述**: 标准化后的问题标题
- **生成规则**: 
  - 简洁明了，一句话概括
  - 面向后续归并和去重
  - 去除情绪化表达
  - 使用标准术语
- **示例**: 
  - 原始: "这个破功能又坏了，烦死了！"
  - 标准化: "功能异常无法使用"

#### 反馈人
- **类型**: 用户（多选）
- **描述**: 消息发送者的姓名
- **来源**: 飞书消息的 sender
- **默认值**: "匿名用户"（如无法获取）
- **示例**: `["张三"]`

#### 反馈原文
- **类型**: 文本
- **描述**: 原始消息文本内容
- **来源**: 飞书消息的 content.text
- **处理**: 保持原始内容，不做修改
- **示例**: "昨天还能正常使用，今天就报错了"

#### 问题分类
- **类型**: 选择（单选）
- **可选值**（默认分类标准）: 
  - `技术问题`
  - `产品建议`
  - `使用咨询`
  - `待划定`
- **自定义分类**: 用户提供具体分类时，只允许用户定义的值
- **描述**: 问题的四大分类之一（默认标准）
- **默认值**: `待划定`
- **约束**: 不允许为空字符串

#### 跟进状态
- **类型**: 选择（单选）
- **可选值**: 
  - `待跟进`
  - `已完成`
  - `重复问题`
- **描述**: 反馈的处理状态
- **默认值**: `待跟进`
- **判定规则**:
  - 有回复 → `已完成`
  - 无回复 → `待跟进`
  - 与已有记录重复 → `重复问题`

#### 来自群聊
- **类型**: 选择（单选）
- **描述**: 反馈来源的群聊名称
- **来源**: 用户配置的群名
- **示例**: "本地版答疑群"

#### 反馈入口
- **类型**: 选择（单选）
- **描述**: 反馈的来源入口
- **固定值**: `群聊`
- **说明**: 当前版本仅支持群聊入口

### 可选字段

#### 回答人
- **类型**: 用户（多选）
- **描述**: 回复反馈的人员姓名
- **来源**: 群聊回复消息的 sender
- **约束**: 
  - `跟进状态` 为 `待跟进` 或 `重复问题` 时为空字符串 `""`
  - `跟进状态` 为 `已完成` 时不得为空
- **示例**: `["李四"]`

#### 回复内容
- **类型**: 文本
- **描述**: 群聊中对反馈的回复文本
- **来源**: 群聊回复消息的 content
- **约束**: 
  - `跟进状态` 为 `待跟进` 或 `重复问题` 时为空字符串 `""`
  - `跟进状态` 为 `已完成` 时不得为空
- **示例**: "请尝试重启应用后再试"

#### 是否命中知识库
- **类型**: 选择（单选）
- **可选值**: 
  - `是`
  - `否`
- **描述**: 是否在知识库中找到对应问题
- **约束**: 
  - 用户未提供知识库时不填充，为空字符串 `""`
  - 提供知识库时，仅当 `问题分类` 为 `技术问题`、`产品建议` 或 `使用咨询` 时填写
  - 其他分类为空字符串 `""`
- **默认值**: 空字符串 `""`

#### 反馈图片
- **类型**: 附件数组 或 URL
- **描述**: 反馈中包含的图片
- **来源**: 群聊消息中的图片附件
- **配置**: 根据用户配置的字段类型决定
  - 附件类型: `["file_token_xxx"]`
  - URL类型: `"https://..."`
  - 混合类型: 同时保存两者
- **默认值**: 空字符串 `""`

## 自定义字段映射

### 映射规则

用户可以自定义标准字段到目标表格实际字段的映射关系：

```json
{
  "SourceID": "消息ID",
  "反馈时间": "创建时间",
  "standard_title": "问题标题",
  "反馈人": "用户",
  "反馈原文": "原始内容",
  "问题分类": "分类",
  "回答人": "处理人",
  "回复内容": "处理结果",
  "跟进状态": "状态",
  "来自群聊": "来源群",
  "是否命中知识库": "知识库命中",
  "反馈入口": "入口",
  "反馈图片": "截图"
}
```

### 字段类型兼容性

| 标准字段类型 | 目标字段类型 | 兼容性 | 说明 |
|------------|-------------|--------|------|
| 文本 | 文本 | ✅ 完全兼容 | 直接映射 |
| 文本 | 数字 | ⚠️ 需转换 | 仅当内容为数字时 |
| 文本 | 日期 | ⚠️ 需转换 | 需符合日期格式 |
| 用户 | 用户 | ✅ 完全兼容 | 支持单选/多选 |
| 用户 | 文本 | ⚠️ 需转换 | 转为用户名 |
| 选择 | 选择 | ✅ 完全兼容 | 选项值需匹配 |
| 选择 | 文本 | ✅ 完全兼容 | 直接映射选项值 |
| 日期时间 | 日期时间 | ✅ 完全兼容 | 格式需一致 |
| 附件 | 附件 | ✅ 完全兼容 | 直接映射 |
| 附件 | URL | ⚠️ 需转换 | 提取URL信息 |

## 字段验证规则

### 必需字段验证

所有记录必须包含以下字段，不得省略：

```json
{
  "SourceID": "必须存在",
  "反馈时间": "必须存在",
  "standard_title": "必须存在",
  "反馈人": "必须存在",
  "反馈原文": "必须存在",
  "问题分类": "必须存在",
  "跟进状态": "必须存在",
  "来自群聊": "必须存在",
  "反馈入口": "必须存在"
}
```

### 枚举值验证

#### 问题分类
- 允许值（默认标准）: `["技术问题", "产品建议", "使用咨询", "待划定"]`
- 自定义分类时: 只允许用户定义的值
- 验证: 严格匹配，不允许其他值

#### 跟进状态
- 允许值: `["待跟进", "已完成", "重复问题"]`
- 验证: 严格匹配，不允许其他值或空字符串

#### 是否命中知识库
- 允许值: `["是", "否", ""]`
- 验证: 仅在特定分类下填写，其他情况为空字符串

### 关联字段验证

#### 回复字段一致性
```javascript
if (跟进状态 === "待跟进" || 跟进状态 === "重复问题") {
  回答人 === "";
  回复内容 === "";
} else if (跟进状态 === "已完成") {
  回答人 !== "";
  回复内容 !== "";
}
```

#### 知识库字段约束
```javascript
if (用户未提供知识库) {
  是否命中知识库 === "";
} else if (问题分类 === "技术问题" || 问题分类 === "产品建议" || 问题分类 === "使用咨询") {
  是否命中知识库 === "是" || "否";
} else {
  是否命中知识库 === "";
}
```

## 空值处理规则

### 文本字段
- 空字符串: `""`
- 不允许: `null` 或省略字段

### 用户字段
- 空值: `[]`（空数组）
- 单个用户: `["用户名"]`
- 多个用户: `["用户1", "用户2"]`

### 附件字段
- 无附件: `""`（空字符串）
- 单个附件: `["file_token_xxx"]`
- 多个附件: `["token1", "token2"]`

### 选择字段
- 未选择: 根据字段类型决定
  - 单选: 默认值或空字符串
  - 多选: `[]`（空数组）

## 字段顺序要求

输出 JSON 中的字段顺序必须与用户配置的字段映射顺序一致：

```json
{
  "collected_items": [
    {
      "SourceID": "",
      "反馈时间": "",
      "standard_title": "",
      "反馈人": "",
      "反馈原文": "",
      "问题分类": "",
      "回答人": "",
      "回复内容": "",
      "跟进状态": "",
      "来自群聊": "",
      "是否命中知识库": "",
      "反馈入口": "",
      "反馈图片": ""
    }
  ]
}
```

## 特殊场景处理

### 匿名用户
当无法获取发送者信息时：
- `反馈人`: `["匿名用户"]`
- `回答人`: `["匿名用户"]`

### 时间解析失败
当时间解析失败时：
- `反馈时间`: 使用当前时间
- 记录警告日志

### 图片处理失败
当图片上传失败时：
- `反馈图片`: 填写错误描述
- 不影响其他字段处理

### 知识库读取失败
当知识库读取失败时：
- `是否命中知识库`: `"否"`
- `问题分类`: `"待划定"`

## 字段映射最佳实践

1. **保持一致性**: 使用统一的字段命名规范
2. **类型匹配**: 确保源字段和目标字段类型兼容
3. **默认值**: 为可选字段设置合理的默认值
4. **验证规则**: 在写入前进行字段验证
5. **错误处理**: 对字段转换失败进行适当处理
