# 用户反馈收集与分类技能

## 概述

`feedback-collect-classify` 是一个专门用于从飞书群聊中自动收集、分类和标准化用户反馈的技能。它能够智能识别有效反馈，补足上下文信息，并按照默认四大分类（技术问题、产品建议、使用咨询、待划定）输出结构化结果，支持直接写入飞书多维表格。用户也可在配置阶段提供自定义分类标准。

## 主要功能

- **自动消息拉取**：从指定飞书群聊按时间窗口自动拉取消息
- **智能反馈筛选**：自动过滤无效消息，识别有价值的用户反馈
- **上下文补全**：对依赖前文的短消息自动补充上下文信息
- **四大分类系统**（默认分类标准）：
  - 技术问题：本应可用但实际异常、报错、失效等问题
  - 产品建议：用户对产品功能、交互、体验等提出的新增/修改建议或期望
  - 使用咨询：用户询问如何使用、权限申请、收费理解等问题
  - 待划定：信息不足或无法稳定分类的问题
- **标准化处理**：生成标准化标题，便于后续归并和知识库检索
- **图片处理**：支持反馈图片的提取、上传和关联
- **重复问题识别**：与已有记录进行语义比对，标记重复问题
- **多维表格写入**：支持自定义字段映射，直接写入目标表格

## 适用场景

- 飞书群聊用户反馈的定期收集和整理
- 反馈表的初始化和数据填充
- 问题池归并前的数据预处理
- 用户反馈的自动化分类和标准化
- 产品团队的用户声音收集和分析

## 调度规则

技能内置了智能时间窗口调度规则：

- **周一执行**：拉取上周五（周一前最近一个工作日）00:00 ~ 23:59 的消息
- **周二 ~ 周五执行**：拉取前一天 00:00 ~ 23:59 的消息
- **周六、周日**：不执行，会提示用户该流程仅在周一至周五执行

## 快速开始

### 基本使用

1. **确认目标多维表格**
   - 提供 Base URL 或 base_token
   - 提供目标 table token 或表名
   - 确认字段映射（可使用默认映射）

2. **确认目标群聊**
   - 提供群名或群链接
   - 技能会自动定位 chat_id

3. **确认时间窗口**
   - 可自定义时间范围
   - 或使用默认调度规则

4. **执行收集**
   - 技能自动拉取消息、处理分类、写入表格

### 默认字段映射

如果未提供自定义字段映射，技能使用以下标准字段：

- `SourceID`: 消息唯一标识
- `来自群聊`: 群聊名称
- `反馈原文`: 原始消息文本
- `反馈入口`: 固定填写"群聊"
- `问题分类`: 技术问题/产品建议/使用咨询/待划定（默认；用户提供具体分类时使用用户分类标准）
- `反馈人`: 消息发送者
- `回复内容`: 群聊回复文本
- `回答人`: 回复者姓名
- `反馈时间`: 消息发送时间
- `standard_title`: 标准化标题
- `是否命中知识库`: 是/否/空字符串
- `跟进状态`: 待跟进/已完成/重复问题
- `反馈图片`: 图片URL或附件token

## 核心特性

### 智能筛选

技能会自动过滤以下内容：
- 公告通知
- 群管理动作
- 纯回复动作（如"试一下重装"）
- 单纯附和（如"+1"）
- 纯情绪表达
- 闲聊内容
- 信息不足且无法补足的内容

### 上下文补全

对于依赖前文的短消息，技能会：
- 向前查看同线程或同时间段最近 3-5 条消息
- 找到最近一个完整问题描述
- 用一句话总结上下文

### 置信度评估

对每条反馈进行置信度评分（0-100）：
- **90-100**：信息明确，分类无明显歧义
- **80-89**：有上下文支撑，分类较稳定
- **70-79**：基本可判断，但有轻微歧义
- **60-69**：信息不足，分类不稳定
- **<60**：严重缺少信息，需要人工复核

置信度低于 70 的反馈自动归为"待划定"。

### 重复问题识别

技能会与已有记录进行语义比对：
- 判定标准：与已有记录的 `standard_title` 语义等价
- 标记方式：`跟进状态` 设为"重复问题"
- 字段处理：`回答人` 和 `回复内容` 设为空字符串

## 图片处理

技能支持完整的图片处理流程：

1. **提取**：从群聊消息中提取图片信息
2. **下载**：下载图片到本地临时目录
3. **上传**：上传到指定云空间文件夹
4. **关联**：根据配置关联到对应记录字段

支持多种图片字段类型：
- **附件类型**：使用文件 token，支持预览和下载
- **URL类型**：使用图片 URL，点击可跳转查看
- **混合类型**：同时保存 token 和 URL

## 知识库集成

当任务要求判断"是否命中知识库"时：

- 仅对 `技术问题` 和 `使用咨询` 分类进行判断
- 命中标准：知识库中已存在语义等价或同类标准问题，且答案稳定
- 读取失败时：填 `否`，并将 `问题分类` 设为 `待划定`
- 未指定知识库：字段保持空字符串

## 配置选项

### 多维表格配置

- **Base URL/Token**: 目标多维表格标识
- **Table Token/Name**: 目标数据表标识
- **字段映射**: 自定义字段对应关系
- **图片字段**: 图片存储字段配置

### 群聊配置

- **群名/群链接**: 目标群聊标识
- **时间窗口**: 自定义或默认调度规则

### 处理配置

- **知识库判断**: 是否启用知识库命中判断
- **图片处理**: 是否处理反馈图片
- **重复识别**: 是否启用重复问题识别

## 注意事项

1. **权限要求**：需要具备目标群聊的读取权限和目标多维表格的写入权限
2. **时间格式**：时间窗口使用 ISO 格式，技能会自动处理时区转换
3. **数据量限制**：单次处理建议不超过 1000 条消息，大量数据建议分批处理
4. **图片大小**：支持飞书平台允许的图片大小限制
5. **分类准确性**：分类结果基于语义分析，复杂情况可能需要人工复核

## 最佳实践

1. **定期执行**：建议按工作日定期执行，保持反馈数据的时效性
2. **字段标准化**：使用统一的字段命名和格式，便于后续分析
3. **知识库维护**：定期更新知识库，提高命中判断准确性
4. **重复问题处理**：定期清理重复问题，保持反馈表的整洁
5. **图片管理**：合理规划云空间文件夹结构，便于图片管理

## 故障排除

### 常见问题

**Q: 群聊消息无法读取？**
A: 检查是否有群聊的读取权限，确认群名或链接是否正确。

**Q: 多维表格写入失败？**
A: 检查表格权限，确认字段映射是否正确，验证字段类型是否匹配。

**Q: 图片上传失败？**
A: 检查云空间权限，确认文件夹 token 是否正确，验证图片格式是否支持。

**Q: 分类结果不准确？**
A: 复杂反馈可能需要人工复核，可以通过调整上下文补全策略改善。

**Q: 重复问题识别有误？**
A: 语义比对可能存在误差，可以定期人工审核重复问题标记。
